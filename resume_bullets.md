# Resume Bullet Points

These bullet points are designed to be high-impact, metrics-driven, and utilize strong action verbs for a Data Analyst / BI Developer resume.

- **Architected an End-to-End HR Analytics Solution:** Designed and implemented a comprehensive ETL pipeline using Python (Pandas/NumPy) to process a 1.4K+ record HR dataset, engineering 7+ advanced business features including Attrition Risk Scores and Income Bands.
- **Developed Enterprise Data Models:** Built a highly optimized Star Schema (1 Fact, 4 Dimension tables) from raw CSVs, enabling efficient querying and seamless integration with BI tools like Power BI and Streamlit.
- **Executed Advanced SQL Analytics:** Authored complex SQL queries utilizing CTEs, Window Functions, and aggregations to identify top attrition drivers, revealing a 3x higher turnover rate among employees working frequent overtime.
- **Programmed Interactive Dashboards:** Engineered a multi-page, interactive web application using Streamlit and Plotly, providing HR executives with dynamic KPI monitoring and drill-down capabilities for workforce risk analysis.
- **Authored Advanced DAX Measures:** Formulated complex DAX calculations (CALCULATE, FILTER, context transitions) to build dynamic, responsive KPIs for Total Employees, Retention Rates, and Departmental Attrition filtering.
- **Automated Executive Reporting:** Developed a Python script (`python-pptx`) to automate the generation of a 12-slide executive presentation, translating raw data models into actionable business storytelling for C-level stakeholders.
- **Delivered Strategic Business Insights:** Analyzed tenure and compensation trends to identify a "Mid-Tenure Slump" flight risk, proposing compensation banding restructuring and career-pathing initiatives to improve retention ROI.
